商品价格与库存监控操作指南

系统用途

本系统用于监控商品价格、库存和异常情况。用户导入需要监控的 URL 后，后台工作流会提取商品名称、规格、价格和库存，并将结果保存到本地数据库。

导入 URL

  • 点击「导入URL」，上传 Excel、XLS 或 CSV 文件。
  • 文件必须包含固定表头「上游1」，系统只读取该列中的非空 URL。
  • 系统只导入 1688.com 及其子域名 URL，其他域名会单独计入「非1688 URL」。
  • 导入采用合并去重模式：已有 URL 不重复写入，失效状态不会因重新导入而改变。
  • 导入完成后会显示新增 URL、重复 URL、无效或空值、非1688 URL 的数量。

监控报警

  • 页面默认展示「监控报警」，列表按检查时间倒序排列。
  • 命中类型包括「商品缺失」「价格上涨」「低库存」。同一商品命中多个类型时会在同一单元格内分行展示。
  • 价格变化带「¥」标识，库存变化不带币种；缺失值显示为「-」。
  • 点击来源 URL 可在新页面打开原始商品页面。

URL 监控

  • 「URL监控」展示已导入 URL、已提取商品数、最近检查时间、状态和操作。
  • 点击 URL 打开原始页面；点击商品数会切换到「商品查询」并按该 URL 筛选商品。
  • 状态分为「正常」「失效」「异常」。表头可按状态筛选，也可选择「全部」清除筛选。
  • 点击「标记失效」后，该 URL 仍保留在列表中，但后台工作流会跳过；点击「恢复有效」后重新参与监控。

商品查询

  • 「商品查询」支持按商品名称模糊搜索，也支持按 URL 搜索。
  • 商品名称和 URL 同时填写时，结果需要同时满足两个条件。
  • 搜索栏左侧会显示当前查询到的商品数量；结果列表每页展示 20 条。
  • 商品价格统一带「¥」标识，库存等非价格数字不带币种。

设置

  • 点击「设置」可配置监控参数。
  • 「监控最大并发数」控制每批最多同时处理的有效 URL 数量，允许范围为 1-50，默认值为 1。
  • 「库存预警值」用于判断低库存，必须大于等于 1，默认值为 100。库存小于该值时会生成低库存报警。

后台工作流

  • 工作流会批量检查所有有效 URL，单个 URL 失败不会阻断其他 URL。
  • 处理成功时会更新商品价格、库存和 URL 最近检查时间；处理失败时会记录错误并在 URL 状态中显示异常。
  • 如果历史商品本次没有被提取到，且历史库存不为 0，系统会将其视为商品缺失并记录报警。
